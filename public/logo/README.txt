Folder: public/logo/
====================
Folder ini digunakan khusus untuk menyimpan asset logo website Villa Bukit Bunga Pacet.

File Utama:
- logo.svg (atau logo.png)

Jika Anda memiliki file logo sendiri:
1. Cukup masukkan file logo Anda ke dalam folder ini dengan nama:
   - logo.svg (jika format SVG)
   atau
   - logo.png (jika format PNG)
2. Logo akan otomatis tampil seragam di:
   - Navbar Header atas (layouts/app.blade.php)
   - Footer bawah website (layouts/app.blade.php)
   - Sidebar Panel Admin (layouts/admin.blade.php)
   - Halaman Login (auth/login.blade.php)
   - Halaman Register (auth/register.blade.php)
   - Favicon tab browser (layouts/app.blade.php)
